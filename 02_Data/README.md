# 02 — Data

## NYC Taxi Trip Record Data

**Project Period:** 03/08/2025 — Present  
**Data Domain:** Transportation & Urban Mobility  
**Primary Source:** NYC Taxi & Limousine Commission (TLC)

---

## 📊 Dataset Overview

This project uses publicly available New York City taxi trip-record data published by the **NYC Taxi & Limousine Commission (TLC)**.

The dataset contains detailed information about individual taxi trips and provides an opportunity to investigate travel demand, trip characteristics, fares, payment behavior, and geographic patterns across New York City.

The data will be used as the foundation for the project's cleaning, exploratory analysis, SQL analysis, visualization, and business intelligence stages.

---

## 🎯 Why This Dataset?

NYC taxi trip data provides a realistic business dataset with millions of transportation records.

It allows us to investigate questions such as:

- When is taxi demand highest?
- How long are typical taxi trips?
- How does distance affect fare?
- Which locations generate the most taxi activity?
- How do passengers pay for trips?
- How does tipping behavior vary?
- What unusual or invalid records exist in the data?

---

## 📋 Main Data Categories

The yellow-taxi trip records include information relating to:

| Category | Examples |
|---|---|
| Trip Time | Pickup and drop-off date/time |
| Location | Pickup and drop-off location IDs |
| Trip Characteristics | Trip distance, passenger count |
| Fare | Fare amount, extra charges, surcharges |
| Payment | Payment type |
| Tipping | Tip amount |
| Rate | Rate code information |
| Service | Taxi/vendor-related identifiers |

---

## 🔎 Planned Data Preparation

Before analysis, the dataset will be assessed and cleaned for:

- Missing values
- Duplicate records
- Invalid timestamps
- Zero or negative trip distances
- Unrealistic trip distances
- Invalid or negative fares
- Unusual passenger counts
- Outliers
- Inconsistent records

The cleaning process will be documented separately
